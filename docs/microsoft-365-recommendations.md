# Microsoft 365 Recommendations For Inga

Research date: 2026-05-17

Microsoft's comparison page lists Microsoft 365 Family as a one-to-six-person subscription with Office apps, each person using up to five devices simultaneously, and up to 6 TB of secure cloud storage total, with 1 TB per person. It also lists Defender, Teams, Designer, Clipchamp, Forms, Outlook, OneNote, and ongoing support as included. Microsoft notes that AI benefits in Family are for the subscription owner only.

Primary source: https://www.microsoft.com/en-us/microsoft-365/buy/compare-all-microsoft-365-products

## Best Uses For A Solo Real Estate Landing Page Workflow

1. Use OneDrive as the media and document vault.
   Store headshots, listing photos, brand assets, review screenshots, logos, license documents, and website copy drafts. Keep a clear folder structure so site assets can later move into `public/images/` cleanly.

2. Use Word for polished bio, email, and listing copy drafts.
   Draft the long bio, short bio, service blurbs, and client-facing templates there before we adapt them into the site.

3. Use Excel for link, review, and content tracking.
   Track profile URLs, review counts, Zillow/Experience facts, video URLs, local content ideas, QR code locations, and follow-up tasks.

4. Use Outlook as the public inquiry command center.
   Make sure website mailto inquiries, GoHighLevel notices, YouTube/contact notifications, and review requests land in organized folders.

5. Use OneNote for neighborhood and client-question notes.
   Capture repeat buyer questions, relocation notes, neighborhood talking points, property management FAQs, and video ideas.

6. Use Clipchamp for simple video repurposing.
   Create short vertical clips from YouTube videos, open-house recaps, neighborhood snippets, and quick FAQ content. The Microsoft page lists 4K export, brand kits, filters, and effects for paid plans.

7. Use Microsoft Designer for lightweight branded graphics.
   Create simple social graphics, YouTube thumbnails, QR-code cards, and review quote graphics. Keep final brand assets in OneDrive.

8. Use Microsoft Defender for personal device and identity security.
   For a solo agent handling client communication, device/account hygiene matters. Turn on security monitoring where available and keep MFA enabled on Microsoft, Google, GoHighLevel, domain registrar, GitHub, and social profiles.

9. Use Forms only for internal or lightweight questionnaires.
   Forms can collect discovery questions, but the public website lead path should still prefer GoHighLevel when those public embed values are ready.

## Important Caveats

- If Inga is a shared family member and not the subscription owner, Microsoft's comparison page says Family AI benefits are for the subscription owner only.
- Microsoft 365 Family is a consumer plan. If Inga later needs custom-domain business email, shared mailboxes, audit/compliance controls, or business-grade admin, evaluate Microsoft 365 Business Basic or Business Standard.
- Do not store private API keys, GoHighLevel secrets, domain credentials, or recovery codes in this repository. Use a password manager.
